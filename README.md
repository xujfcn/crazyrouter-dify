# 🔮 Dify + Crazyrouter

> Connect Dify platform to 300+ AI models via Crazyrouter.

## ⚡ Setup
1. Open Dify → Settings → Model Provider
2. Add **OpenAI-API-compatible** provider
3. API Base URL: `https://crazyrouter.com/v1`
4. API Key: `sk-your-crazyrouter-key`
5. Add models: `gpt-4o`, `claude-sonnet-4-20250514`, etc.
